## 🛠️ Tecnologie & Strumenti

### Frontend & Mobile Development
* **Linguaggi:** JavaScript (ES6+), TypeScript
* **Framework & Librerie:** React, Next.js, React Native, Expo
* **Mobile Ecosystem:** Sviluppo Cross-Platform Nativo, Gestione Asset
* **Styling & Animazioni:** Tailwind CSS, GSAP (GreenSock)

### Backend, Database & CMS
* **Runtime & Architetture:** Node.js, Server Actions (Next.js)
* **Backend-as-a-Service (BaaS):** Supabase (PostgreSQL, Realtime Data, Auth, Storage)
* **Headless CMS:** Sanity.io (Modellazione schemi, Integrazione dynamic promo-banner)

### Tools & Infrastruttura
* **Package Manager:** pnpm/npm
* **Hosting & Cloud:** Vercel

### 🚀 Progetti in Evidenza nel Portfolio

* **Salone di Bellezza & Dynamic CMS:** Landing page commerciale performante controllata da remoto tramite Sanity CMS. Include la logica per la gestione dinamica del menù trattamenti, una gallery personalizzabile e un banner promozionale condizionale basato sullo stato del database.
* **Bar Concept (Client Portal):** Piattaforma web ad alte prestazioni per i clienti del locale con menù interattivo, filtri di ricerca in tempo reale e form di prenotazione tavoli integrato con Supabase.
* **Bar Concept (Staff Dashboard):** Applicazione mobile nativa sviluppata in React Native ed Expo per il personale di sala. Gestisce le prenotazioni e lo stato dei tavoli con sincronizzazione realtime e notifiche push acustiche immediate sul dispositivo, inoltre vi è la possiblità di cambiare il menu aggiornando le voci già presenti o aggiungendone nuove.
